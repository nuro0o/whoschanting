# Expansion character portraits

Created 2026-09-13 with the built-in image_gen tool. Five individual portraits use the original illustrated ensemble as the style authority and the existing Tidecaller portrait as a secondary framing reference. Each final PNG is copied unchanged from the generated output, preserving image metadata; no raster post-processing was applied.

All are 1254 × 1254 square portraits intended for store previews and character selection. The five identities have distinct faction clothing, props and silhouettes while retaining dark ink contours, angular opaque gouache planes, muted village colors and expressive faces.

## In-game availability

Each of the five faction expansions includes its matching character for the purchaser, including existing paid orders placed before these portraits were added. As with other unlocks, a verified account is required. Room guests share access to faction gameplay; the character belongs to its owner and can be worn in any game mode with any role. Refunds and disputes revoke access. No database migration or Stripe product change is required for these runtime entitlements. Existing order and receipt snapshots are preserved.

The store shows each portrait, its name, and a larger preview. Owners can open the wardrobe directly from their expansion card. The wardrobe and character picker list them under **Expansion characters**; visitors can see locked portraits without gaining access.
